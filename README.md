# backend_Alex

Este repositório contém o acompanhamento prático do cronograma de estudos de desenvolvimento back-end, focando em fundamentos essenciais e estruturas de dados.

**Status do Projeto:** Em evolução constante, seguindo o cronograma de aulas de desenvolvimento back-end.

## Stack
- **Linguagem:** JavaScript (Node.js)
- **Foco:** Estruturas de Dados, Programação Assíncrona, Promises e Fundamentos de Back-end.

## Estrutura
```text
backend_Alex/
├── exercicios_estrutura_dados/  # Resoluções de exercícios (Filas, Pilhas, Listas)
└── fundamentos/                 # Conceitos base: Async/Await, Promises, Event Loop

```

## Conteúdos Principais

* **Estruturas de Dados:** Implementação e prática com Filas, Pilhas e Listas Encadeadas.
* **JavaScript Assíncrono:** Estudos sobre Event Loop, Promises (resolve/reject) e Async/Await.
